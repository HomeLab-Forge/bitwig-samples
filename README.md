# bitwig-samples

Free sample libraries ported to Bitwig Studio: drum kits as Drum Machine
presets, and pianos, keys, basses, guitars, strings and synths as Sampler
presets, each with its sounds as Bitwig `.multisample` files too. All are made
from SFZ libraries. Each library is its own release; this repository holds this
guide and the tools. The ports are made by the tools in [`drums/`](drums/) and
[`tools/`](tools/) (MIT, see [LICENSE](LICENSE)) from each library's own SFZ
program at its default settings.

This is not an official Bitwig project and is not affiliated with Bitwig GmbH.

**Not using Bitwig?** Use the original library instead; each release page
links to it. Bitwig cannot load SFZ, which is the only reason these ports
exist: an SFZ player gets more from the original, with every microphone and
control.

## Releases

One library per release, tagged `bitwig-samples-<slug>-v<version>` and
titled `Bitwig <Library>`, for example `bitwig-samples-swirly-drums-v1.0`,
`Bitwig Swirly Drums`. Each release page lists the original library, its
authors and licence, how the port differs from the original, and every file
or instrument with its keys and velocity layers. A new version of a library
moves its row in [Libraries](#libraries) to the new release, in the same change.

A port carries the licence of the library it was made from. Most are CC0 or
public domain; some are CC BY or CC BY-SA, which ask for credit (the release
page gives the line to use) and, for BY-SA, that sample libraries made from
them are shared under the same licence. Music you make with any of them
is yours.

## What a release holds

A drum kit:

- **`<Kit>.bwpreset`**: a Drum Machine preset, samples inside.
- **`<Kit>.multisample`**: the whole kit on one Sampler, on the original
  library's keymap.
- **One `.multisample` per articulation**: each drum sound on its own, at its
  original note, for a Drum Machine pad or a Sampler of its own.
- Large kits are split into several `.tar` assets, each under GitHub's 2 GiB
  limit.

A piano, keys, bass, guitar, strings or synth library:

- **One `.bwpreset` per instrument**: a Sampler preset, samples inside. Each
  is one of the library's SFZ programs; download only the ones you want.
- **`<slug>-multisamples.tar`**: every instrument as a `.multisample`.
  Round robins keep their first take; legato, keyswitches and
  controller-driven articulations are not carried over.

A preset's **Perform** remote page holds **Mod Tone**, a low-pass cutoff:
turned down, the sound darkens. The BW_AKAI controller script in
[audio-rig](https://github.com/HomeLab-Forge/audio-rig) puts it on the mod
wheel, and on a Drum Machine copies it to every pad.

A `.multisample` is Bitwig's own format: a zip of 24-bit WAV files plus a
`multisample.xml` keymap. Velocity layers and round robins are kept; the
original's microphones are mixed down to stereo.

## Install

1. **Download** the assets from the library's release page.
2. **Unpack** any `.tar` asset:
   - Linux and macOS: `tar xf <file>.tar`
   - Windows: open it with 7-Zip, or run `tar xf <file>.tar` in a terminal.

   Do not unzip the `.multisample` files themselves; Bitwig reads them as they
   are.
3. **Move** any `.bwpreset` into your library's preset folder for its
   device, `Presets/Sampler/` or `Presets/Drum Machine/`, under
   - Linux: `~/Bitwig Studio/Library/`
   - macOS and Windows: `Documents/Bitwig Studio/Library/`

   It then shows up in the Browser under its device and category.
4. **Move** the `.multisample` files into a folder Bitwig indexes. The simplest
   is your library's multisample folder, in a subfolder per kit:
   - Linux: `~/Bitwig Studio/Library/Multisamples/`
   - macOS and Windows: `Documents/Bitwig Studio/Library/Multisamples/`

   Any other folder works once you add it under **Settings → Locations → My
   Library**.
5. **Rescan** if the library does not show up: in the Browser, right-click **My
   Library** and choose **Rescan**.
6. **Play** it:
   - A Sampler preset: drag it onto an instrument track.
   - The whole kit: drag `<Kit>.multisample` onto an instrument track. It opens
     in a Sampler on the original keymap, listed on the release page.
   - A Drum Machine of your own: add a Drum Machine and drag each
     articulation's `.multisample` onto the pad you want. Set each pad's
     Sampler to **One-shot** so hits ring out after the note ends, and make
     the closed hi-hat pads choke the open one.
